# 86,400 Seconds
#### Productivity
### Change how you see time.

> “We all say we don't have enough time — yet every day gives us 86,400 seconds.”

---

## Inspiration
Most productivity struggles begin with a simple belief:  
**“I don’t have time.”**

We usually measure time in hours and minutes, which makes it feel limited and quickly disappearing.  
This project was created to **change the perspective of seeing time** by representing the entire day as **seconds (0 – 86,399)** — reminding us that every day actually provides **86,400 small opportunities** to begin something meaningful.

**Main Motto:**  
> Changing the perspective of seeing time — to stop the thought that *“I don’t have time.”*

---

## Project Overview
**86,400 Seconds** is a Windows-styled responsive web application that dynamically displays the **number of seconds elapsed since midnight**, updating every second in real time across all devices.

The design is intentionally minimal, clean, and focused — allowing the viewer to **feel the passage of time differently**, not just read it.

---

## Features
- Displays **seconds elapsed since midnight**
- Real-time **1-second interval updates**
- Automatic **midnight reset**
- **Windows 10/11 inspired UI**
- Fully **responsive design** (mobile, tablet, desktop)
- Implemented as a **single lightweight HTML file**
